# Changelog

## 1.0.0 — 2026-10-11
First public release. Tested with Cyberpunk 2077 2.31.
- Portal gun item (Militech Saratoga base) with the HD Portalgun Remastered model, glow, name, description (en, ru)
  and an inventory icon at vanilla size.
- Blue / orange portals on static surfaces: a glowing shot from the gun, animated portals opening from a point.
- See-through view between the two portals (up to ~20 m).
- Walking through with the speed kept and turned; NPCs go through as ragdolls.
- Keyboard bindings in the Cyber Engine Tweaks overlay.
